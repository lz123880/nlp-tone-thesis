# 管理层语调与企业未来经营业绩——基于 A 股上市公司年报 MD\&A 文本的 NLP 测度

> 预演毕业论文（NLP 测度构建方法课程作业）· 全流程可复现
>
> - **研究问题**：在控制当期业绩后，年报 MD\&A 的管理层语调能否预测企业未来一年的经营业绩？其预测力是否随语调可信度而变化？
> - **数据**：**全部为真实公开披露数据**。年报原文来自巨潮资讯网公开检索接口（40 家非金融 A 股公司 × 2022—2024 三个财年，目标 120 份 PDF，实际下载 114 份、抽取成功 112 份）；财务指标来自东方财富数据中心 F10（总资产净利率等，年报口径）。**不存在任何模拟或生成数据**；唯一自建材料是情感词典（教学演示版），属测量工具而非数据。
> - **方法**：词典法净语调（否定词翻转 + 程度副词加权）+ TF-IDF 逻辑回归弱监督替代测度 + 句级语调离散度；双向固定效应面板回归（公司聚类稳健标准误）；分半信度 / 聚合效度 / 已知组效度 / 预测效度四项信效度检验；替代测度、替代业绩、逐年剔除、分半复核、安慰剂置换五组稳健性检验。

## 五步复现流程（一键跑通）

```bash
pip install -r requirements.txt

cd code
python 01_download_reports.py     # ① 语料与财务数据（约 10-20 分钟）
python 02_text_preprocess.py      # ② MD&A 抽取与分词
python 03_build_measures.py       # ③ 语调测度 + 信效度检验
python 04_merge_panel.py          # ④ 企业-年度面板
python 05_analysis.py             # ⑤ 描述统计 + 回归 + 图 1-3
python 06_robustness.py           # ⑥ 稳健性 + 安慰剂 + 图 4-6
python 07_export_docx.py          # ⑦ 生成 Word 版论文
```

各模块严格按顺序执行、以上一模块落盘文件为输入，任何一步都可独立重跑。第 ③—⑦ 步在已有数据文件的前提下无需重复下载年报。所有随机过程固定种子（机器学习分类器 42、安慰剂置换 2026），结果可精确复现。

## 主要结果速览

**语调测度的信效度（`output/tables/tab_reliability.csv`）**

| 检验                        | 统计量           | 取值                   |
| ------------------------- | ------------- | -------------------- |
| 分半信度（Spearman-Brown 校正）   | r_SB          | **0.9496**           |
| 聚合效度（词典法 vs 机器学习法）        | Pearson r     | **0.5432**           |
| 已知组效度（增长组 vs 下滑组）         | Welch t / p   | **3.4688 / 0.0008**  |
| 预测效度（TONE_t 与 ROA\_{t+1}） | Pearson r / p | **0.3876 / <0.0001** |
| 机器学习测度 5 折交叉验证            | 准确率 / AUC     | **0.8133 / 0.8471**  |

**基准回归（`output/tables/tab4_main_reg.csv`，被解释变量 ROA\_{t+1}，语调百分数口径）**

| 模型                 | TONE 系数 | t 值  | p 值        | N   | R²    |
| ------------------ | ------- | ---- | ---------- | --- | ----- |
| (1) 年度 FE          | 1.574   | 2.24 | 0.0249\*\* | 112 | 0.191 |
| (2) (1)+控制变量       | 1.124   | 2.41 | 0.0158\*\* | 112 | 0.512 |
| (3) (2)+当期 ROA（H2） | 0.451   | 1.82 | 0.0692*    | 112 | 0.762 |
| (4) 公司+年度 FE+控制变量  | 0.091   | 0.34 | 0.7343     | 112 | 0.907 |

**结论**：H1（前瞻性信息）与 H2（增量信息）得到支持——控制当期业绩后语调仍具边际显著的增量预测力，1000 次安慰剂置换的 p 值为 **0.009**（`output/tables/tab7_placebo.csv`）。H3（策略性语调）未获支持：语调×过度乐观（系数 0.140，p=0.6878）与语调×高杠杆（系数 0.550，p=0.1211）交互项均不显著。模型 (4) 系数坍塌提示语调预测力主要来自公司间横截面差异而非公司内时序变异。
